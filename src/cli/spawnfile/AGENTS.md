# Spawnfile CLI handoff

Consumes the public spawnfile.training-context.v1 receipt without importing its
compiler. Verify pinned source bytes and confined document mappings before use.
Source pins hash raw bytes with the producer's 16 MiB limit; selected prompt
resources have their own strict text validation. Never decode inventory bytes.
The receipt is evaluator metadata, never a substitute native instruction file.

Dry-run may resolve candidates, cases and costs, but never compiles, authenticates
or executes an agent. Native runs require their supported isolated preparation;
do not route a compiled Daimon project through the generic Pi adapter.
Test mutations, ambiguous mappings, unsupported execution and canonical identity.

moments.ts owns named per-trial moment dispatch. Require frozen identity, fresh control/moment, successful rewind evidence and a bound receipt before native start. Domain reconstruction stays in registered integrations.
Authored moment.role/example/dataset select rewind; trial.phase selects evaluation.
Internal validation may execute an authored train moment without relabeling it.
Reject every other cross-role execution; test automatic and group-selected holdouts
through the CLI and bind rewind evidence to the authored role, not the trial phase.

session.ts composes the declared shared-container session: supervisor reset,
canonical candidate compilation, named moment reconstruction and native child
execution. One persisted slot freshness store is shared with the native adapter.
Bind the broker declaration and clock to canonical agent/moment metadata. Verify
post-capture reset before releasing a lease or publishing trial completion.
session-evidence.ts snapshots bounded preflight bytes and digest before native
execution. Protected preparation retains these bytes, never only the supervisor's
mutable pathname; closure snapshots the reset proof for its own generation.
Domain hooks own runtime config/state/transport projection; never copy credentials
or introduce domain-specific queue coordinators. session-paths.ts only binds
fresh evaluator scratch to empty, canonical leased writable roots. Run adjacent
session/path tests plus stored-trial and native CLI integration tests.

declaration.ts receives --spawnfile-execution, validates command/slots/hooks, then
calls the optional public Spawnfile receiver through adapters/spawnfile. It wires
bound compiler/reset operations and generic fresh rewind into session.ts. Domain
registrations never supply compiler operations or per-trial credential realms.

Declaration registrations may supply only native transport delivery and child
external-input callbacks. Activation projects these callbacks explicitly; compiler
operations, child execution kind, leases and freshness stay public-owned.
Declaration subprocess tests require an explicitly provisioned paired compiler via
SPAWNFILE_TEST_SOURCE_ROOT. Never discover a developer sibling checkout or override
the caller's compiler selection; CI must pin a receiver-capable revision.
